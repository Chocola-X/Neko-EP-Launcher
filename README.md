# Neko-EP-Launcher

> Linux 桌面端 EnergyPlus 图形化启动与建模分析工具，基于 PySide6（Qt for Python）开发。
> 面向建筑节能 / 遮阳方向的研究与工程人员，提供从 **IDF 字段感知编辑**、**多窗口模型对比与参数迁移**、**一键模拟运行**、**结果结构化分析**、**时序曲线可视化** 到 **单文件离线报告导出** 的全流程工作台体验。
> 
> 代码仓库：[https://github.com/Chocola-X/Neko-EP-Launcher](https://github.com/Chocola-X/Neko-EP-Launcher)  
> 许可证：**GNU Affero General Public License v3（AGPL v3）**

当前版本针对 **EnergyPlus 9.4.0** 深度适配并兼容 9.x 系列。项目路线图见 [ROADMAP.md](ROADMAP.md)。

## 功能特性一览

- 🎨 **双模式 IDF 建模**：
  - **对象树与元数据属性表**：按类型智能分组浏览，基于 `Energy+.idd` 元数据提供下拉选项、单位提示、必填标记及实时数值开闭区间标红校验；
  - **高保真源码编辑器**：保留行号、语法高亮与当前行高亮，长行原生平滑滚动；文本输入 600ms 低延迟与对象树双向同步，单行多对象与行尾注释精准解析。
- 🪟 **多窗口协同与模型对比**：
  - 支持快捷键或菜单开启多个独立的主窗口，各自独立加载不同 IDF 模型、运行模拟与查看结果；
  - **跨窗口对象互通**：对象树支持通过 `Ctrl+C` / `Ctrl+V` 将完整对象定义以 IDF 语法在不同窗口间无缝复制粘贴；
  - **跨窗口参数批量迁移**：属性面板支持一键「📋 复制全部参数」与「📥 粘贴覆盖参数」，迅速完成模型间参数复用。
- ⚡ **非阻塞模拟编排**：
  - 完整建模 EnergyPlus 命令行选项（全年/设计日模拟、ReadVars、EPMacro、ExpandObjects 等）；
  - 默认启用「生成分析数据」：在独立运行副本中注入 SQLite 及汇总请求，不篡改原始 IDF 文件；
  - 非阻塞异步运行，实时日志输出，模拟完成自动归档至 `data/runs/<run_id>/`。
- 📊 **结构化结果分析与可视化**：
  - **错误诊断**：`.err` 错误与警告按级别分类表格化，支持快速定位对应 IDF 对象；
  - **汇总报告**：结构化解析 `eplustbl.xml`（及 HTML/SQLite 降级），查看负荷与能耗汇总表；
  - **交互式时序曲线**：直读 `eplusout.sql` 时序库，支持多变量叠加显示、环境周期与时间区间筛选、不同单位自动分图、图形缩放及导出 PNG / 完整 CSV；
  - **能耗图表**：对汇总数据绘制能耗占比柱状图与饼图；
  - **可用变量提取**：搜索 `eplusout.rdd` / `.mdd` 字典，一键向当前模型追加变量输出请求。
- 📑 **单文件离线增强 HTML 报告**：
  - 自动提取状态诊断、能耗概览柱状图、代表性时序曲线（SVG）及全部可折叠筛选的汇总表格；
  - 样式、矢量图与轻量筛选脚本完全内嵌，无需网络即可双击直接打开或外发交付。
- 🖥️ **原生桌面交互**：
  - 支持「跟随系统」原生外观，亦可自由切换深色 / 浅色主题。

## 环境准备与快速启动

### 环境要求

| 项 | 要求 |
|----|------|
| 操作系统 | Linux（KDE Plasma、GNOME 等主流桌面环境） |
| Python | >= 3.10 |
| EnergyPlus | 9.4.0（本地已安装，在工具设置中指定路径即可） |

### 安装步骤

```bash
# 1. 克隆仓库
git clone https://github.com/Chocola-X/Neko-EP-Launcher.git
cd Neko-EP-Launcher

# 2. 配置 Python 虚拟环境
python3 -m venv .venv
source .venv/bin/activate

# 3. 安装依赖
pip install -r requirements.txt
```

### 启动与首次配置

```bash
python main.py
```

首次运行进入 **工具 → 设置**，配置 EnergyPlus 安装目录（需包含 `energyplus` 可执行程序与 `Energy+.idd`）及默认天气文件目录即可开始使用。

## 核心使用说明

### 1. IDF 建模与属性编辑

- **打开模型**：
  - 通过 **文件 → 打开（Ctrl+O）** 选择已有 IDF，或 **文件 → 打开示例** 浏览 EnergyPlus 官方样例库；
  - 打开后默认聚焦右侧 **属性编辑** 工作区，单击左侧对象即可直观查看与编辑字段。
- **元数据驱动属性编辑**：
  - `choice` 与 `object-list` 引用字段自动呈现可搜索下拉列表；
  - 显示字段单位、默认值及必填标识；非法输入即时标红警示并提示错误原因；
  - 修改后按 **Enter** 或切换字段即自动提交；**Ctrl+S** 保存前会自动提交焦点所在的编辑框，并采用原地保真替换策略，最大程度保留原文注释与排版。
- **源码与对象树双向同步**：
  - 通过顶部工具栏或标签页切换到 **IDF 源码** 进行文本编辑，支持长行水平平滑滚动；
  - 文本停止输入 600ms 后自动同步至对象树；若源码存在语法错误，字段编辑面板会自动保护性禁用，避免覆盖未完成的文本。
- **校验模型**：
  - 点击 **编辑 → 校验 IDF** 或工具栏「校验当前模型」，弹窗呈现必填缺失、类型范围不符及无效引用的完整报告，窗口支持拖动缩放与一键复制报告。

### 2. 多窗口协同与模型对比

- **新建独立窗口**：
  - 点击 **文件 → 新建窗口（Ctrl+Shift+N）** 或工具栏「新建程序窗口」按钮，即可开启全新的主界面；
  - 通过 **文件 → 在新窗口中打开...（Ctrl+Shift+O）** 可直接在新窗口中载入目标 IDF 文件；
- **独立运行与对比**：
  - 多个窗口互不干扰，可并排停靠，分别加载基准模型与对比模型（例如普通外窗与可调遮阳模型）；
  - 单个窗口关闭不影响其他窗口，所有窗口全部关闭后程序正常安全退出。

### 3. 跨窗口对象与参数相互复制

- **对象级复制与粘贴**：
  - 在源窗口左侧对象树中选中任意对象，按 **Ctrl+C**（或右键菜单「复制对象」）；
  - 切换到目标窗口的对象树中按 **Ctrl+V**（或右键菜单「粘贴对象」），系统将自动解析并在目标模型中追加该对象，同步更新属性面板与源码，并自动选中新对象；
  - 右键菜单亦提供「复制为 JSON」、「复制对象参数列表」及「创建对象副本」。
- **参数级批量覆盖复制**：
  - 在源窗口的属性编辑面板底部，点击 **📋 复制全部参数**；
  - 切换到目标窗口中的同类型对象，在属性面板点击 **📥 粘贴覆盖参数**，即可将对应字段值一键批量迁移覆盖。

### 4. 模拟运行编排

- **配置运行**：
  - 展开主窗口底部的「运行配置与日志」面板，选择对应气象文件（EPW），可选填自定义运行 ID（留空默认按时间戳生成）；
  - 可勾选全年模拟（-a）、仅设计日模拟（-D）、运行 ReadVars（-r）、展开宏（-m）与几何扩展（-x）等官方参数；
- **生成分析数据**：
  - 默认保持勾选「生成分析数据」：启动器会在归档的运行副本中自动配置 SQLite 输出与表格汇总，无需手工向原 IDF 中加入 `Output:SQLite` 等配置；
- **实时模拟**：
  - 点击 **运行 EnergyPlus（F5）** 启动非阻塞模拟，运行日志在面板中实时滚动输出；
  - 模拟全部输入（IDF/EPW 副本）与输出产物均完整归档至 `data/runs/<run_id>/` 目录。

### 5. 计算结果分析与可视化

- **自动加载与结果查看**：
  - 运行结束后自动切换至主工作区「结果分析」，亦可通过 **文件 → 打开结果目录** 查看历史运行产物；
  - 工作区包含 6 个子分析标签：
    1. **错误诊断**：表格化呈现 `.err` 日志，按警告级别分类，支持双击定位至具体对象；
    2. **汇总报告**：结构化展示 `eplustbl.xml` 中的全量能耗与负荷汇总表格；
    3. **时序曲线**：读取 `eplusout.sql`，支持搜索并勾选多个变量、按环境周期与日期筛选、缩放平移、导出高清 PNG 及完整 CSV 数据；
    4. **能耗图表**：对汇总表格数据绘制柱状图与饼图；
    5. **可用输出变量**：搜索 `.rdd` / `.mdd` 字典，可直接点击「添加选中变量到当前 IDF」并插入每小时输出请求；
    6. **原始文件**：浏览并预览当前运行产生的全部底层文件。
- **单文件离线增强 HTML 报告**：
  - 运行面板勾选「运行结束后生成增强 HTML 报告」后，系统将在运行目录生成 `enhanced-report.html`；
  - 包含模拟状态、诊断警示、能耗图表、多周期时序曲线（SVG）及支持全文搜索过滤的全部汇总表格；
  - 单文件自包含，脱机环境下直接双击用浏览器打开，方便研讨交付。

### 6. 运行历史与系统外观

- **运行历史**：点击 **运行 → 运行历史** 打开管理面板，支持按 IDF 名称与成功状态筛选历史模拟，双击记录即可在主工作区重载结果进行复盘。
- **系统主题**：进入 **工具 → 设置 → 通用**，默认采用「跟随系统（原生外观）」，无缝融合 KDE Plasma 或 GNOME 桌面，支持浅色/深色主题动态应用。

## 快捷键一览

| 快捷键 | 功能操作 |
|--------|----------|
| **Ctrl + N** | 新建空白 IDF 文件 |
| **Ctrl + Shift + N** | 新建程序主窗口 |
| **Ctrl + O** | 打开已有 IDF 文件 |
| **Ctrl + Shift + O** | 在新窗口中打开 IDF 文件 |
| **Ctrl + S** | 保存当前 IDF 模型 |
| **Ctrl + Shift + S** | 当前模型另存为 |
| **Ctrl + C / Ctrl + V** | 复制 / 粘贴对象或参数（对象树与属性表支持跨窗口） |
| **Ctrl + Z / Ctrl + Y** | 源码撤销 / 重做 |
| **Ctrl + F** | 源码文本查找 |
| **F5** | 运行当前 EnergyPlus 模拟 |
| **Ctrl + Q** | 退出程序 |

## 快速开发指引

本项目处于快速开发迭代阶段，新功能与修复直接在 `master` 分支进行迭代。

```bash
# 安装开发与测试依赖
pip install -r requirements-dev.txt

# 运行代码规范检查与严格类型检查
ruff check .
mypy src

# 运行单元与集成测试套件（CI 门禁全绿要求）
pytest -m "not e2e"

# 检查纯逻辑层测试覆盖率（要求 >= 90%）
pytest tests/unit -q --cov=src/core --cov-fail-under=90
```

## 项目结构简览

```
Neko-EP-Launcher/
├── main.py                 # 应用启动入口
├── pyproject.toml          # 项目元数据与打包构建配置
├── requirements.txt        # 运行时依赖
├── requirements-dev.txt    # 研发与测试依赖
├── docs/                   # 详细开发与规范文档目录
├── src/
│   ├── core/               # 纯逻辑层：无 GUI 依赖、无 I/O 副作用（IDF/IDD/结果解析）
│   ├── services/           # 业务服务层：编排 core，封装 QProcess 与 I/O
│   ├── persistence/        # 持久化层：读写配置与运行归档
│   ├── ui/                 # 表现层：PySide6 桌面窗口、编辑器、对象树与图表组件
│   └── app.py              # 应用依赖注入组装根与多窗口管理
├── tests/                  # 自动化测试镜像（unit / integration / fixtures）
├── resources/              # IDD 缓存与静态资源
└── data/runs/              # 本地模拟运行归档历史（.gitignore 忽略）
```
